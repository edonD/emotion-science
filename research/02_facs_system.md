# FACS — Facial Action Coding System

## Overview
- Developed by Paul Ekman & Wallace V. Friesen (1978), based on Carl-Herman Hjortsjö's anatomy work
- Significantly updated by Ekman, Friesen, and Joseph C. Hager in 2002
- Taxonomizes human facial movements by their appearance on the face
- Designed to be self-instructional

## How It Works
- Decomposes any facial expression into individual **Action Units (AUs)**
- Each AU = specific muscle or muscle group contraction/relaxation
- Human coders can manually code nearly any anatomically possible facial expression
- Temporal segments tracked (onset, apex, offset)

## Action Units (44+ total)

### Upper Face
- AU1 — Inner Brow Raise (Frontalis, pars medialis)
- AU2 — Outer Brow Raise (Frontalis, pars lateralis)
- AU4 — Brow Lowerer (Depressor glabellae, Corrugator supercilii)
- AU5 — Upper Lid Raise (Levator palpebrae superioris)
- AU6 — Cheek Raise (Orbicularis oculi, pars orbitalis)
- AU7 — Lid Tightener (Orbicularis oculi, pars palpebralis)
- AU43 — Eyes Closed (Relaxation of Levator palpebrae)
- AU45 — Blink
- AU46 — Wink

- AU13 — Sharp Lip Puller (Levator anguli oris)
- AU14 — Dimpler (Buccinator)

- AU16 — Lower Lip Depressor (Depressor labii inferioris)

## Intensity Coding
- A = Trace (minimal)
- B = Slight
- C = Marked/Pronounced
- D = Severe/Extreme
- E = Maximum

## Modifiers
- R = Right side only
- L = Left side only
- U = Unilateral (no specific side)
- A = Asymmetric (bilateral, one side stronger)

## Emotion-AU Mappings (Ekman's Framework)

| Emotion | Key Action Units |
|---------|-----------------|
| Happiness | AU6 + AU12 (Duchenne smile) |
| Sadness | AU1 + AU4 + AU15 |
| Surprise | AU1 + AU2 + AU5 + AU26 |
| Fear | AU1 + AU2 + AU4 + AU5 + AU7 + AU20 + AU26 |
| Anger | AU4 + AU5 + AU7 + AU23 + AU24 |
| Disgust | AU9 + AU15 + AU16 |
| Contempt | AU12R + AU14R (unilateral) |

## Applications
- Clinical psychology & psychiatry
- Animation (Pixar, Disney use FACS for character animation)
- AI/ML facial recognition systems
- Law enforcement (interrogation analysis)
- Market research (consumer reactions)
- Human-computer interaction

## Certification
- Self-instructional via manual and workshops
- Certification through standardized testing
- Considered gold standard for facial coding research
